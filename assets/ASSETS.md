# Welcome to the Assets folder!
To get **HDRI Skyboxes** [go to this website](https://polyhaven.com/hdris?ref=hdri-haven) You will be able to automatically change the skybox in the later versions, just not now.

Some important folders/files might've been excluded so here are the folders that assets folder has:
- **fonts**
- **materials**
- **mesh_materials** (auto generated by the program)
- **models**
- **music**
- **scenes**
- **scripts**
- **skybox** (IMPORTANT! This folder must be created & you have to add default_skybox.hdr inside this folder)
- **textures**
- **VAULT_API** (This is where C# API Code goes in release mode)
- **VAULT_OUT** (This is where built C# assemblies go)
